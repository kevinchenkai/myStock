## 目标与当前结论

为六只股票预测下一交易日的低价／高价，辅助人类在低价买入、高价卖出，并在明确本金、库存、费用和持有约束后评估一段时间的权益变化。系统不自动下单。风险覆盖区间与执行报价分开评估：区间覆盖率提高并不等于交易收益提高。

标的为 `US.NVDA`、`US.TSLA`、`US.PDD`、`HK.00700`、`HK.09988`、`HK.01810`，各股独立本币账户，USD 与 HKD 不直接相加。

**工程升级已合入 main 并部署，模型没有晋级。** E0–E5 的训练／校准窗口、波动缩放、模型容量、滚动校准及特征实验没有候选满足预设门槛，未启动五种子晋级复核，也没有独立 holdout 或 60 个真实交易日的前向 shadow。保留现有分位回归 + CQR 模型；完整负结果见 [实验汇总](../records/ml-upgrade-experiment-results_codex_20260904.md)。

## 如何使用

1. 打开本地 [ML 页面](http://127.0.0.1:8888/ml-next/)。下一目标日卡片固定使用有时间证据的 live；读取卡片状态、目标交易日和截止时间。
2. 历史回溯默认包含明确标注的离线重建。选择 20／60／120 个市场交易日，查看预测与实际高低、行情来源、缺口及选中日期的真实挂单事实。
3. 填写初始现金／库存、已有库存价格、单笔数量、库存上限、最大持有天数及证券 lot／tick，点击“重新模拟当前窗口”。合成测试按钮只填浏览器表单，不能代表真实账户。
4. 对比三种固定策略的现金、库存、费用、权益和回撤。每个窗口从输入的初始状态重新模拟；窗口结果不能相加成连续收益。

受约束回放提供 `boundary_inventory`（预测边界）、`naive_vol_inventory`（波动率基准）、`fixed_offset_inventory`（固定偏移）。下单时预留现金／库存，DAY 到期释放，不允许裸空或透支。小时 OHLC 无法还原逐笔先后和排队，同柱歧义使用明确的保守次序。费用空白标为 gross／费用缺失；填写测试费率也不代表真实券商费用。

真实挂单使用订单快照事实；没有完整改单／撤单生命周期，不能把事后预测强行对齐为当时可用建议，也不计算“假如替换真实订单”的确定收益。

## 数据与可追溯性

| 对象 | 当前口径 |
| --- | --- |
| 生产库 `data/mystock.db` | 交易／持仓等事实；ML 只读取快照，Web 只读查询 |
| ML 库 `data/ml/mystock_ml.db` | 独立日线、小时线、交易事实副本、旧预测投影及新版本表；详见 [数据字典](data-dictionary_claude_20260623.md) |
| `ml_prediction_versions` | 新预测按 run 追加；内容与历史不可覆盖／删除，生命周期时间单独记录 |
| `ml_predictions` | 兼容旧接口的投影；后续只投影有效 live，已有旧混合来源逐行标注 |
| `data/ml/runs/<run_id>/` | 冻结 `input.db`、SHA256、代码／依赖／特征／seed、日历版本、训练和校准截止 |
| `data/ml/reports/runs/<run_id>/` | 每次报告原文归档；latest 仅兼容副本，全跳过不覆盖旧报告 |
| `data/ml/receipts/` | 训练与发布回执；采集单独使用 `.data.json`，不授权发布 |

`live`、`backfill`（历史 HTML 导入）、`recomputed`（事后重建）不得混为一种证据。旧时间不明确的记录只作审计，迁移不追认发布时间；历史重建不是前向 shadow。

2026-09-05 部署验收时，六股近 20／60／120 session 分别有 120／360／720 条 `ok` 历史行，无缺行情、预测或小时线；另生成并发布六条 live。该数字是当时的检查结果，不保证未来自动完整。部署中的历史重算使用独立冻结输入并追加版本，保留旧预测及交易事实，没有整库覆盖。修复流程见 [历史补齐记录](../records/ml-history-refresh_codex_20260905.md)，当前生产结果以 [部署回执](../records/ml-deployment_codex_20260905.md) 为准。

## 时间守卫与接口

日历覆盖 2020–2027，处理市场时区、休市与半日市；US 决策截止 09:30 ET，HK 09:00 香港时间。日线需满足收盘确认，特征末日必须等于所需 as_of；盘中、旧缓存、缺特征或日历越界会拒绝生成。日历剩余不足 60 天告警，临时停市仍需维护，见 [日历说明](../../mystock/ml/calendars/README.md)。

| GET 接口 | 用途 |
| --- | --- |
| `/api/ml/v2/latest` | 版本与时间状态；API 默认 live，页面卡片固定 live |
| `/api/ml/v2/review` | 固定 session 窗口与缺口；`source=recomputed` 允许历史重建；`selected=YYYY-MM-DD` 附带当天订单事实 |
| `/api/ml/v2/compare` | 三种固定策略的受约束回放，场景参数须显式输入 |
| `/api/ml/strategy` | 默认 schema 1 旧模拟；显式 `mode=inventory` 切换受约束口径 |

没有独立 `/api/ml/v2/facts` 路由。参数非法返回 400，缺库／缺 schema 返回 503；Web 不抓取、不训练、不写库。旧模拟的成交额／配对成本收益率与库存模式的初始权益收益率不能直接比较。

## 人工运行与发布

以下在已配置的项目根目录执行。仅查看既有数据无需运行采集或训练。

```bash
# 需要刷新生产账户事实时单独运行；不是 ML 训练的自动副作用：
bash scripts/update.sh
# ML 日线／小时线及生产事实快照：
bash scripts/ml.sh data
# 收盘确认后生成预测与报告，记录终端打印的 Train receipt：
bash scripts/ml.sh train
# 需要公开发布时，明确填写本次 train 返回的路径：
bash scripts/ml.sh publish <Train-receipt路径>
```

`publish` 校验回执、产物哈希和目标截止；过期不得重发为当天建议。`all` 包含采集、训练和公网发布，任一采集失败会中止；无参数只显示帮助。当前没有 cron／launchd 自动任务。公网只覆盖静态报告首页，不上传本地日期归档或开放账户 Web。

本地入口为 8888；[公网报告](https://g.ismayday.com/mystock/) 随人工发布更新。运行、排错及恢复见 [工程交接](../records/ml-upgrade-handoff_codex_20260904.md)。

## 接下来维护什么

- 逐证券 lot／tick 的历史有效期及页面预填；现有规则快照会覆盖，HK 100 只是合成测试参数。
- 冻结输入的保留／恢复策略；当前每个 run 完整备份数据库，不得直接删除版本所引用的证据。
- 采集部分成功协议、单行过滤计数、市场本地默认回溯日期、本地 Web 可见时间证据及报告展示改造。
- 真实费用、账户初始状态与分红付款日；付款日未知时分红只计应收，缺行情的估值显示 stale。
- 后续特征和模型实验仍须遵守时点可用性及独立验证；外部特征、E6–E8、RL／TFT／HMM 不属于本次完成范围。
