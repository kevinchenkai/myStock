## 4. 解读与限制

- **主力两只稳定通过**：腾讯两侧 8%–15%、阿里 16%–32%，两个窗口方向一致，五个种子极差约 1–4 个百分点，配对块区间下限均在 4% 以上。
- **小米无一致改善**：XIACY 低侧约 0、高侧 4%–7%；KWEB 在 W1 低侧 +7%／高侧 +3%，W2 低侧 0／高侧 +18%，两窗口不一致。小米的 ADR 薄、训练行少（W2 仅 185），按用户口径列为观察，不进主判定，也不建议为它单独调参。
- W2 与 W1 相邻且训练期重叠，不是相互独立的证据；W2 未被此前实验查看过，但其选择只依赖 W1 之前的数据这一点成立。
- 仍未做：前向 shadow、费用后策略回放、普通日／跳空日分报、财报日分报；live 留档尚未记录开盘前决策时刻。
- 改善来自"开盘前已知的隔夜信息"，与人工决策时点强绑定：只有在美股收盘后、港股 09:00 前生成预测才成立。若仍在港股收盘后生成，则该特征不可用。

## 5. 建议

1. 腾讯、阿里进入 **D5 前向 shadow**：每个港股交易日在美股收盘后、09:00 HKT 前用 O2 生成预测并留档（含决策时刻），与现行收盘后预测并行对照，至少 60 个 session。这一步需要 `predict_next_day` 的 V2 入口与 live 留档的决策时刻字段（D5 工程范围），仍不切换生产默认。
2. 小米保持观察，沿用现行模型；不为它扩展代理搜索。
3. 美股两只主力（英伟达、特斯拉）不适用本机制（隔夜信息弱），其"盘前参考价"口径另立讨论。
